# Delivery 12 - PDF Reports for All Application Sections

## Objective

Add downloadable PDF reports inside the PowerGym application for all main operational sections. Reports are generated by the backend from MySQL data, so they reflect the database state created by migrations, seed data, and user activity.

## New application area

A new **Reports** menu item is available in the sidebar for authorized users. The page allows users to generate PDFs for:

- All Sections Summary
- Members
- Staff / Employees
- Payroll
- Accounting & Finance
- Scheduled Group Classes
- Private PT Sessions
- Plans, Subscriptions & Invoices
- Support & Notifications
- Security & Audit

## New APIs

```txt
GET /api/reports/sections
GET /api/reports/:section.pdf
```

Supported `:section` values:

```txt
all
members
staff
payroll
accounting
classes
private-pt
plans-subscriptions
support
security
```

## Report behavior

- Reports are protected by the existing JWT session middleware.
- Reports are role-aware; users only see sections permitted for their role.
- PDFs are generated server-side from MySQL using `jspdf` and `jspdf-autotable`.
- The accounting and consolidated reports accept optional `from` and `to` query parameters.
- The PDF response uses `Content-Disposition: attachment` so browsers download the file.

## User workflow

1. Run the app with `npm run dev`.
2. Open `http://localhost:3000`.
3. Log in as an authorized user.
4. Open **Reports** from the sidebar.
5. Select a date range if needed.
6. Click **Download PDF** for any section or **Download Full Report**.
